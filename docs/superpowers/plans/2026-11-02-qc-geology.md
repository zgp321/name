# 质量诊断与地质/钻孔联合解释实施计划

## 1. 纯数据模块（先测后写）

- 新增 `mine_tem/quality.py`：QC 汇总、时间门摘要和诊断数据校验。
- 新增 `mine_tem/geology.py`：别名标准化、钻孔区间校验、候选异常几何关联。
- 新增单元测试覆盖空数据、无效深度、重叠区间、SNR/QC 统计、伪深度关联和没有关联时的稳定输出。

## 2. 结果与成果契约

- 在 `Result` 生命周期中保存可选的地质叠加数据，不改变 `process()` 的默认返回行为。
- 扩展 `export.py`，以同一事务写入 QC/钻孔 CSV，并在 manifest 增加摘要；旧成果目录、无钻孔导出和失败回滚保持兼容。
- 增加导出回归测试和 CLI 演示验证。

## 3. GUI

- 在结果页加入 QC 与联合解释标签，复用现有只读表和 Matplotlib Canvas。
- 钻孔导入走 Task，任务失败不覆盖当前 `Result`；处理参数/测线变化清空诊断状态。
- 测点选择只刷新诊断图，不触发重新处理；联合解释图清楚标注伪深度几何对照。
- 增加 offscreen GUI 测试：结果显示、QC 选择、钻孔导入/错误恢复、标签页和控件忙碌状态。

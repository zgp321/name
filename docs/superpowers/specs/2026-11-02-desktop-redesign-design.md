# TEM 工作台界面重设计（待用户确认）

## 目标与依据

用户选择“优先界面和操作体验”，并选择“重新设计整体布局和视觉风格”。本设计将现有功能重新组织为便于连续操作的中文桌面工作台；不是扩展物理算法或提升识别准确率。以下布局、颜色和具体交互是我的提案，尚未视为用户已确认。

当前技术为 PySide6 + Matplotlib，四个标签页分别负责导入、参数、判读、训练。已实际复现：预览表编辑不影响原始数据；切换测线仍可导出上一测线结果；处理期间仍能从其他入口发起任务。基线测试为 8 passed、1 skipped（无 torch）。

## 方案比较

1. 保留标签页并修补状态：改动小，用户已选择整体重设计，因此不作为主方案。
2. **推荐：PySide6 左侧导航 + 顶部上下文 + 内容工作区 + 统一任务状态**。保留计算和导出接口，重建界面层；比修改配色工作量大，但能一起理顺操作流程。
3. 改为 Web 界面：便于远程使用，但需要新增服务、部署和图表交互实现；当前仍以 Windows 桌面交付为主，不采用。

用户已选整体重设计；其中具体采用方案 2 是本次建议，待确认。技术保持 Python/PySide6，不引入 Web 服务或额外 UI 框架。

## 布局与视觉

- 左侧深色窄导航：数据与测线、处理参数、结果判读、模型训练；底部保留“研究原型 / 需人工复核”标识。
- 顶部显示当前页面标题、当前测线及操作提示，不将路径、堆栈等技术信息放在主标题中。
- 主工作区采用浅灰背景、白色卡片、蓝绿色主操作色；警告用琥珀色，失败用红色，选中和忙碌状态同时使用文字与颜色。
- 信息层级：页面标题 → 下一步提示 → 操作工具栏 → 数据 / 图表 → 详细记录。主按钮每页一个，使用明确动词。
- 默认窗口约 1360×860，最小约 1024×720；参数页和训练页可滚动，结果图与表可拖动调整比例。小屏幕不得遮挡操作按钮或参数。
- 中文字体使用系统可用字体回退，不依赖联网字体；表格只读、交替行色、支持选择复制；图表提供 Matplotlib 的缩放、平移、复位工具栏。

## 页面与操作

### 数据与测线

空状态解释支持的格式和单位，提供“导入测线文件”和“使用合成演示”。加载后显示文件来源、测线数、测点数和时间门数，测线选择器与只读前 100 行预览并列呈现。明确显示“仅预览前 100 行，处理使用全部数据”，避免误以为只计算可见行。主要下一步为“核对处理参数”。导入失败保留原有有效数据，错误对话框提供简短原因与可展开详情。

### 处理参数

按“发射 / 接收系统”“质量控制与候选阈值”“显示与解释假设”分组；所有字段保留单位及原有默认值。提供“恢复默认参数”，改变任何参与结果的参数即令结果过期。引擎在此页选择，并显示快速模式与可选 SimPEG 的适用范围。缺少可选依赖时显示原因，不能使基础模式不可用。主要操作为“运行当前测线”。

### 结果判读

顶部显示测点数、有效 / 总门数、拒绝门数、候选区数。中间为衰减曲线 / 伪剖面 / 2.5D 示意切换及图表工具，底部为中文列名的候选表与质量明细。导出仅对与当前数据、测线、参数和引擎一致且已完成的结果开放。表头中文映射只作用于界面，导出文件 schema 保持不变。无结果时显示下一步；无候选区时明确显示“未检出满足当前阈值的低阻候选区”，不推断无水害。

### 模型训练

说明所需成对 NPZ 数据、没有预训练模型、与快速处理互相独立。提供数据集选择、模型前缀、轮次、训练和当前测线推理，附只读训练日志。缺少 torch 时解释功能不可用的原因，用户仍可使用其余页面。可选依赖通过模块发现检查，不在 GUI 主线程导入重量级 torch / SimPEG；实际导入错误由后台任务报告。

## 状态与后台任务

- 统一管理空数据、待处理、运行中、成功、失败、结果过期。重新导入、更换测线、修改参数或引擎时，清空旧图、候选表、摘要并关闭导出，显示重新处理提示。
- 所有任务通过统一启动方法管理，同一时刻只允许一个任务；检查层和按钮层都防止重复发起。运行期间禁用导入、改参、换线、训练、推理和导出；可浏览页面及日志。
- 文件解析和成果写出放入后台，与现有计算 / 训练共用任务生命周期；Qt 控件和图表画布仅在主线程更新。Matplotlib 导出与界面图表操作串行，导出期间禁用图表交互，避免并发绘图。
- 完成或失败后等待线程真正 finished 再恢复可操作状态；异常不能只留在 stderr。失败清楚说明本次操作未完成，详细堆栈放可展开详情 / 日志。
- 不提供虚假的百分比或强制终止线程。训练有真实轮次时显示进度文字；其余任务使用不确定进度。运行期间关闭窗口显示“任务运行中，请完成后关闭”，拒绝关闭，不调用 terminate。
- 每个结果记录生成时的数据与参数上下文；训练完成不得覆盖现有测线结果或误报测线处理成功。训练 / 推理失败遵循各自状态恢复，不留下可导出的过期结果。

## 验收与不做事项

无显示模式下自动验证：主窗口四导航切换；空数据提示；数据预览只读；导入失败保留旧数据；演示处理完成；改线 / 改参使结果过期；运行时重复启动被拒绝；运行时关闭被拒绝；任务失败恢复；异步导出后 JSON/CSV/PNG 文件完整。保留原有核心测试与 CLI 演示检查，并核对相同配置的数值结果不变。

本次不改变 CSV/NPZ/JSON 格式、默认物理算法、训练算法或候选判据；不增加实时仪器接入、严格二维/三维反演、自动判水、项目数据库、账号或 Web 部署。Windows 真实交互、高 DPI、屏幕阅读器和 EXE 打包须在目标系统另行验证；Linux offscreen 检查不能替代。

## 交付步骤与风险

用户确认设计后，编写实施计划，再先建立状态与线程回归测试，重建界面并验证。尽量保留 create_window、main 和 CLI 接口；确有需要时抽出 GUI 状态与任务辅助模块，不把数值计算复制到界面层。交付源码、测试、中文变更记录以及可下载 ZIP；当前为 ZIP 导入目录，没有本地 Git 历史，不擅自推送到远端。

布局样稿见同目录 desktop-redesign-preview.html。样稿使用固定示例数字，按钮只演示导航，不读取数据或计算，不能当作功能已实现的证据。

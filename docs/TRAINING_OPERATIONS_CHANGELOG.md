# 训练操作优化 · 2026-11-02

## 本次交付

- 训练页按“数据检查 → 保存配置 → 训练监控 → 模型选择”组织，延续侧边导航和卡片视觉，小窗口可滚动操作。
- 后台检查 NPZ，显示样本数、门数、层数、时间/深度范围与标签范围；不依赖 PyTorch。数据路径变化会清除旧检查状态。
- 补齐 load_pairs 的时间/深度轴校验；时间有限且大于零、深度有限且不小于零，轴严格递增。GUI 检查和实际训练复用同一规则。
- 后台任务通过结构化轮次信号更新真实进度、训练/验证 MSE 和两条曲线；训练早停保留实际完成轮次。训练成功后显示已保存模型的验证损失。
- 保存位置与现有模型均可浏览选择，自动匹配 .pt 与 _metadata.npz。检查均值/尺度的维数、有限性和正尺度；仅检查元数据，不反序列化权重。
- 成功训练后自动定位新模型；检查操作和训练成功保留已有测线快速处理成果，更换已用于推理的模型会使旧推理结果失效。
- 推理后台每次重新检查模型元数据，防止曾经通过的模型文件后来变更，也不能绕过失败检查。保留原有推理时间门匹配和质量拒绝。
- 训练/推理函数签名、网络结构、归一化方法、8:2 划分、学习率、早停和文件命名不变。保存前缀即使字面上以 .pt 结尾，也保留原 API 的输出命名，不误报训练失败。

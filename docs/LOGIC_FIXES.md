# 六项逻辑漏洞修复 · 2026-11-02

## 修复范围

1. `learn.predict` 对反归一化电阻率执行有限值和严格正数检查，拒绝上溢、下溢到零、NaN；提示核对输入分布。异常提取同时忽略非正及非有限电阻率，防止无效预测变成低阻候选区。没有给预测值强行截断，也没有改变网络或物理公式。
2. 快速处理按原始时间顺序，将有效门划为连续区段，各区段独立建立视深度插值；质控拒绝门会打断插值支持，不再跨过空缺拼出连续剖面。每段至少需三个不同的有效视深度；全部不足时明确失败，不能制造有效剖面。
3. `min_snr` 现在参与实际门拒绝判断。低于噪声底与高于噪声底但未达到最低 SNR 分别记录；可选基线校正后也重新检查最低 SNR。
4. 测点大间距处对连通域分段编号，保留断点两侧有效候选列；不再直接清空这些列。面积仍是原有伪剖面网格面积估计，不宣称实际含水面积。
5. GUI 开始覆盖当前推理所依赖的同一模型前缀时，立即清除旧推理结果并禁用导出。按规范化路径比较，训练失败也不恢复可能过期的推理。普通快速处理结果和其他模型的训练沿用原有状态规则。
6. 导出先在目标目录的同级临时目录准备完整成果，保留已有无关文件；全部写完后替换正式目录。图片生成、文件写入或目录提升失败时保留/恢复旧成果；恢复也失败时保留备份，并在错误中给出可恢复路径。首次导出失败不留下半份正式成果。关闭图片导出时移除上一版生成的三个 PNG，避免新表格搭配旧图。

额外修复：先拒绝目标符号链接，再规范化含 `..` 的路径，防止临时目录在目标内部递归复制。禁止将当前工作目录或其父目录直接作为被替换的成果目录；请指定独立子目录，例如 `--output output_demo`。

## 验证

完整测试：**68 passed**；仍有 24 条 Matplotlib Qt 上游弃用警告，无跳过。测试包含真实 CPU PyTorch 短训练与推理、离屏 GUI，以及已有文件格式/处理/导出测试。

CLI 合成演示：43 测点、1419 门，1415 有效门、1 个低阻候选区；所有 NPZ 数组与原健康演示基线逐元素一致（含 NaN 位置）。修复后的真实外部数据可能因最低 SNR 和空缺保留规则而拒绝更多门、出现空白区域，这是质控生效后的预期差异。

独立审查发现的 `..` 递归复制问题已经先失败后通过的回归测试修正；没有未处理的其他 Critical/Important/Minor 审查项。

## 限制与后续方向

- 导出具备普通异常回滚，不保证两次目录重命名之间突然断电时仍原子可见；旧目录副本和新成果需要额外临时磁盘空间。若恢复失败，请保留错误指出的备份目录并手工恢复。

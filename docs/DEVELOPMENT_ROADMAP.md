# 迭代路线图与验收准则

> 当前状态：V1.0 原型。分阶段加固，不得把研究原型直接宣布为现场可靠自动判水工具。

## P0（立即）：可运行、可信的工程基础

**目标**：依赖/打包/CI、GUI 与 CLI 运行、输入与单位验证、稳定错误处理、物理假设与结果溯源。

任务：基础/可选依赖分组；Python 3.12 Windows 环境测试；Qt offscreen smoke；不同编码/时间单位/多测线/缺失门测试；导出模式区分；SimPEG API 对齐与地表 1D 数值基准（可选依赖存在时）。

验收：完整 pytest 通过；CLI 示例可重复；GUI 最小启动/退出有证据；异常输入报可读错误；输出记录参数/数据质量标记/所用算法及限制；不把 1D 拼接、2.5D 示意图称作 2D/3D 反演。

## P1：真实设备接入与质量控制

**目标**：针对一个明确厂商/型号/格式做可测试插件（有规范与样本才能开发）；输入事件、时间门、地理位置、发射与接收几何、线圈匝数、面积、测量分量、关断波形及增益/标定信息标准化。

验收：实现插件 schema + 样本 fixture + 往返/错误单元测试；不会默默猜测关键单位或设备参数；人工确认处理前后曲线；无法处理的金属支护干扰有 QC 拒绝机制。

## P2：物理正演与反演升级

**目标**：以验证后的 SimPEG/其他可信求解器为基础实现**明确几何条件**下的 TEM 正反演；对井下全空间和金属支护耦合要求采用匹配的全空间/复杂几何求解与对照基准，不可用地表层状半空间代替。

验收：已知解析/基准响应上的幅值、时间零点、符号、源收耦合误差达标（阈值须先制定）；引入测量噪声权重与残差图；报告模型分辨率、非唯一性与深度可靠性；与成熟开源 solver 对比并记录版本与许可证。

## P3：物理引导训练与低阻/富水辅助分类

**目标**：沿参考论文的数据/模型/UI 三层思路，使用 TEM 专属正演样本与地质/钻探真值开发可替换的 U-Net/CNN/其他模型；先以物理可检验的视电阻率/反演电阻率和置信度为输出，不给无依据的水体标签。

验收：按矿区/测线分割训练、验证和独立测试，排除泄漏；记录数据来源、随机种子、模型权重、评估集和训练日志；报告低阻异常召回、误报、置信区间、分布外/异常数据退化；与物理反演及人工解译对比。

## P4：成果交付与现场联合验证

**目标**：完善二维/三维展示（所有示意与反演结果明确标注）、可追溯成果报告、打包与部署；与专业人员对接现场验证。

验收：独立地质/钻孔校验报告、设备标定报告、已知失败案例、专家签核；Windows 一键安装/升级与离线运行；仅在完成验证后讨论生产使用范围。

## 非目标

本阶段不做自动采掘放行、不宣称未验证准确率、不以渲染成像代替三维物理反演、不使用未经授权的第三方源代码或实测矿山数据。

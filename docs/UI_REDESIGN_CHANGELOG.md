# 桌面工作台重设计 · 2026-11-02

本次按用户确认的样稿实现 PySide6 桌面界面，不是 Web 页面。保留 create_window/main、CLI、核心计算、训练实现和导出 schema。

## 已实现

- 深色左导航、浅色卡片、顶部当前测线，四个工作区分别为数据、参数、结果和模型。
- 数据预览只读，显示前 100 行并支持 Ctrl+C；后台文件解析失败时保留已加载数据和可用结果。
- 滚动参数分组、恢复默认值、明确单位及可选依赖提示。
- 四项质量统计、中文候选表、质量记录、图表缩放/平移/复位；窗口最小 1024×720，结果页可滚动，图表/表格可拖动分配高度。
- 参数、数据、测线、引擎改变后立即清空旧图、统计和表格，禁用过期成果导出。
- 导入、处理、推理、训练、导出统一后台任务；一项任务运行时拒绝重复任务和窗口关闭，线程 finished 后恢复按钮。训练完成不覆盖已有测线成果。
- 导出在后台写表格及图形；期间暂停界面图表绘制和工具操作，避免并发绘图。导出目录名过滤路径分隔符和 Windows 不支持的字符，发生转换或截断时追加原始 ID 的确定性摘要，避免不同测线映射到同名目录。已有目录属于另一测线、包含未知文件或符号链接时拒绝写入，原始测线标识仍保留于成果内容。
- 对话框显示简明错误及可展开详情，完整错误写入运行日志。空数据文件不会替换此前有效结果。

## 文件

- `mine_tem/gui.py`：保留入口，延迟载入桌面模块。
- `mine_tem/gui_window.py`：导航、页面、控件状态及任务完成处理。
- `mine_tem/gui_support.py`：共享样式、只读复制表格、后台任务和安全目录名。
- `tests/test_gui.py`：真实离屏 Qt 工作流测试；只替换阻塞对话框和一次可选训练的计算体，不冒充真实 PyTorch 训练验证。

## 验证

使用 Python 3.12.14、PySide6 6.12.0、Matplotlib 3.11.2 的 Linux 云环境。测试命令为 `QT_QPA_PLATFORM=offscreen python -m pytest -q`；CLI 为 `python -m mine_tem.cli --demo --output output_demo`。

验证包括导航、只读复制、上下文过期、重复任务、运行中关闭保护、失败恢复、异步导入/导出、目录包含、最小窗口坐标标签、空文件与训练完成状态隔离。演示输入为 43 测点 / 1419 门，1415 有效门；CLI 输出 NPZ 的每个数组与界面修改前完全一致（包括 NaN 位置）。

完整测试结果：**27 passed、1 skipped**；其中 GUI 19 项通过，原有核心测试 8 项通过，PyTorch 实际训练测试因未安装依赖跳过。另有 24 条来自 Matplotlib Qt 后端的同类弃用警告。独立代码审查发现的目录碰撞问题已用先失败后通过的回归测试修复；额外验证不同测线的既有目录不会被覆盖、指向父目录以外的符号链接被拒绝，同一测线可重复导出。

PyTorch 和 SimPEG 未安装，真实训练 / 推理和物理反演未验证；Windows 交互、高 DPI、屏幕阅读器和 EXE 安装包未验证。Matplotlib Qt 后端在窗口 resize 时会发出 `AA_UseHighDpiPixmaps` 上游弃用警告，未关闭警告或改动依赖来掩盖它。

## 解释边界

快速模式仍为地表中心回线晚期半空间近似，视深度是代理量；2.5D 为示意，非真实三维反演；低阻候选区不是积水确证。本次没有修改物理公式、候选判据或提出现场识别准确率。
